# MR News Web App

A modern **news aggregator web application** that lets users browse and search the latest news articles by category and region.

## 📰 Project Overview

MR News is a simple, responsive web application to view up-to-date news headlines from different sources and categories. It is built using modern web technologies and fetches real-time news using a public news API.

## 🚀 Key Features

- Fetches **latest news headlines** using a news API  
- Search news by **keywords**
- Filter news by **categories** (e.g., technology, sports, business)
- Easy-to-use UI with responsive design
- Displays **title, image, and snippet** for each article
- Click an item to open the **full news source**

## 🛠️ Technologies Used

- **HTML**, **CSS**, **JavaScript**
- Fetch API for network requests
- Optional: any CSS framework (e.g., Bootstrap, Tailwind CSS)
